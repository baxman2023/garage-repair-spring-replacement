# Getting started: first funnel today

The first hour decides everything. Follow the checklist on your project page —
it always points at the next unlocked step.

## 1. Create a project and feed the Detective

Create a project, then paste **everything you have** into the Sales Detective:
sales pages, testimonials, support emails, a rambling voice-note transcript.
It extracts a structured product profile and interrogates you only about what
it could not find. Answer in plain language.

## 2. Approve an offer (G0)

The Offer Forge produces offer variants built on your profile — value stack,
risk reversal, price framing. Pick one and approve it. **G0 is a hard gate**:
nothing downstream generates without an approved offer.

## 3. Run the funnel math (G1)

Enter price, margin, refund rate, and channel CPCs. The math gate computes
whether the funnel can pay for traffic. A failing G1 is a feature — it just
saved you the ad spend.

## 4. Diagnose markets and approve the strategy (G2)

The market engine proposes candidate starving crowds; the top five get full
diagnoses (awareness, sophistication, resident emotion, objections, entry
conversation). Review them, adjust ranks if you disagree, and approve the
strategy snapshot. **G2 approval is the milestone** — the whole build unlocks.

## 5. Build

One button fans out the full stack: VSL, sales letter, upsells, emails, ads,
quiz — per market. Watch the grid fill as assets pass the gates. Anything
blocked shows exactly which gate refused it and why.

## 6. Deliver

Approved assets package into build kits (G7) with compiled prompts for your
page builder, UTM message-match maps, and the tracking pixel. Export and ship.

Stuck on any step? Its checklist entry links to the relevant docs page.
