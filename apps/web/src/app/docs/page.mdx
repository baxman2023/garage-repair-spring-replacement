# CopyForge docs

CopyForge turns one product into a complete direct-response funnel — five
diagnosed markets, a full asset stack per market, every asset forced through a
quality gate ladder before you ever see it.

**The path is always the same:**

1. **Sales Detective** — tell it about your product (paste anything; it interrogates for the rest).
2. **Offer Forge (G0)** — variants are forged, you approve one.
3. **Funnel math (G1)** — the economics gate. Unprofitable funnels stop here on purpose.
4. **Markets & strategy (G2)** — five starving-crowd markets diagnosed, a strategy snapshot you approve.
5. **Build** — the fan-out. Every asset runs G3 (Council) → G4 (focus group) → G5 (de-slop) → G6 (compliance) → G7 (packaging).
6. **Delivery** — export build kits, wire the quiz, install the pixel, watch the ledger.

Start with [Getting started](/docs/getting-started), or open the
[read-only sample funnel](/demo) to see a finished 5-market build first.

Every model call runs on **your own Anthropic key** — encrypted at rest, never
logged. Costs are on your key and visible token-by-token under
Settings → Usage & cost.
