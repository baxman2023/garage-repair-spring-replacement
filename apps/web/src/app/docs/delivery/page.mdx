# Delivery & export

Everything CopyForge generates is **yours outright** — full commercial rights,
no watermarks, no attribution required. The rights statement ships inside every
export manifest.

## Build kits (G7)

A packaged asset contains the final block-structured copy, a design brief, the
UTM message-match variant map, and two compiled prompts: one tuned for Macaly
(blocks verbatim, budget-split sections) and one universal prompt targeting a
single-file HTML or Next.js stack.

## Exports

Per-market ZIPs contain markdown + HTML renders of every approved asset plus
the manifest. Deterministic: the same approved content exports byte-identically.

## The quiz

The market-routing quiz is hosted at your project's public quiz URL and also
exports as a self-contained embed snippet — it works from a plain `file://`
page with no framework.

## Tracking

Install the pixel snippet on every page; point Ringba webhooks and email CSV
imports at your project's ingest URL (Settings → Ingest). The ledger drives the
dashboards, control/challenger decisions, and the system's own forecasting —
the more it sees, the sharper it gets.
